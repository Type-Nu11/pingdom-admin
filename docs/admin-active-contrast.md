# 관리자 활성 텍스트 대비 (#164)

브랜드 기본색 #FF1956은 유지한다. 작은 글자는 primaryForeground (#B80F40), 흰 글자를 올리는 선택 탭 배경은 primaryAction (#D41449)을 사용한다.

| 조합 | 이전 | 변경 후 |
| --- | --- | --- |
| 선택 탭 / 흰 글자 | 약 3.80:1 | 5.26:1 |
| 흰 표면 위 선택 메뉴 tint / 핑크 글자 | 약 3.47:1 | 6.04:1 |
| 선택 탭 hover / 흰 글자 | 약 3.80:1 | 6.60:1 |
| surfaceLow / 증빙 버튼 글자 | 미기록 | 6.11:1 |
| surfaceLow 위 tint / 증빙 버튼·비선택 탭 hover | 미기록 | 5.60:1 |

이전 수치는 이슈 #164의 기록을 참고했다. 변경 후 수치는 실제 테마 값과 알파 합성을 사용하는 tests/admin-contrast.test.mjs로 계산한다. 일반 텍스트 목표는 4.5:1이다. 로고와 비활성 컨트롤은 이번 검사 대상에서 제외한다.

적용 범위: 관리자 사이드바 활성·hover 글자 및 focus 테두리, 장소 신청 심사 필터 탭과 증빙 버튼. 다른 상태 색상과 primary의 전역 사용처는 변경하지 않는다.

실제 스타일 컴포넌트를 렌더링한 독립 브라우저 화면에서 1280px·390px 선택 탭 색상, hover 배경과 키보드 focus 테두리를 확인했다. 로그인 후 전체 페이지 통합 QA는 수행하지 않았다.

## 관리자·상점주 범위 확장 (#275)

위 내용은 #164 당시의 범위다. #275에서는 관리자·상점주 공통 버튼, 사이드바,
로그인 역할 선택, 페이지 번호, 날짜·시간 선택, 상태·오류 안내와 알림 건수까지 확장한다.
브랜드 기본색은 유지하고 글자·동작용 배경만 접근 가능한 토큰으로 구분한다.

- 작은 핑크 글자: `primaryForeground` (#B80F40).
- 흰 글자의 주요 동작 배경: `primaryAction` (#D41449), hover는 `primaryForeground`.
- 오류 글자: `errorText` (#B42323), 흰 글자의 위험 동작 배경: `errorAction` (#C42525).
- 비선택 로그인 역할, 안내·placeholder, 달력의 다른 달 날짜: 읽을 수 있는 `muted`.
- 로고, 장식, 테두리의 기존 브랜드·상태 색상은 유지한다. 비활성 컨트롤은 텍스트 대비 검사에서 제외한다.

### 탭 조작

기존 13개 탭 목록에 공통 `AccessibleTabList`를 적용한다. 선택 상태와 패널의
`aria-selected`, `aria-controls`, `aria-labelledby`를 연결하고 Tab 진입 지점을 하나로 둔다.
방향키와 Home/End는 초점만 이동하며 Enter/Space가 기존 클릭 핸들러를 실행한다.
따라서 화면별 입력 보호·조회·처리 중 제약을 우회하지 않는다. 비활성 탭은 건너뛰고,
목록을 벗어나면 선택된 탭이 다시 진입 지점이 된다. 패널 자체도 키보드로 진입 가능하다.

### 검증 방법 및 결과

`npm run test:ui-accessibility-browser`는 복제 CSS가 아닌 실제 스타일 컴포넌트의
계산된 전경·배경색을 검사한다. 알파 배경을 부모 표면까지 합성하며 사용 중인
brightness hover 필터도 계산에 반영한다. 48개 조합의 기본·hover·focus 상태,
총 144건이 4.5:1 이상이며 최저 대비는 4.84:1이다.

실제 로그인·방문자 심사 컴포넌트에서 1920×1080, 1366×768, 390×844 화면을 확인했다.
정상 목록→상세 선택, 빈 결과, 의도적인 조회 실패 안내, 키보드 초점·선택·패널 연결,
방향키 이동 시 추가 요청 없음과 가로 넘침 없음을 회귀 검사한다. 기존 심사 모달 검사는
1280×800, 1280×600, 390×800, 390×600에서 별도로 통과했다.

단위 테스트는 비활성 탭·수직 방향키·단축키·화면별 선택 거절도 확인한다.
브라우저 QA는 GET 전용 합성 응답과 비변경 조작만 사용하고 실제 API·승인·삭제는 차단한다.
이 결과는 운영 인증, 실데이터 업무 처리, 모든 페이지 및 스크린리더의 전체 QA를 대체하지 않으며,
상점주·관리자 통합 검증 이슈 #220·#221은 별도 범위로 남긴다.
