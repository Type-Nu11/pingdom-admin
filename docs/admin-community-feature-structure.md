## 소유권과 보존 규칙

- 라우터는 `/community`, `/community-reports`를 관리자 `ProtectedRoute` 아래에서 각각
  lazy import한다. 기능별 파일 이동으로 페이지/Provider 수명을 바꾸지 않는다.
- `CommunityShared`의 기능 전용 화면 틀·본문/페이지네이션은 community 안에 둔다.
  `AdminLayout`, 공통 `AppDialog`·페이지네이션·알림·Auth/Axios와 공통 메시지를 복제하지 않는다.
- `useCommunityQuery`는 인증/오류 처리와 선택 key·요청 수명에 결합되어 있어
  이름이 범용적이라는 이유만으로 shared로 옮기지 않는다. key 태그·AbortController·
  cleanup·인증 해제와 늦은 응답 배제, 이전 선택 데이터 숨김을 그대로 유지한다.
- 목록 훅은 조회 조건/페이지, 빈 마지막 페이지 보정, 로딩 중 페이지네이션 유지와
  오래된 행 제거를 계속 소유한다. UI의 페이지 전환 후 포커스 복귀도 변경하지 않는다.
- 신고 상세는 글/댓글과 원문 연결을 검증하고, 원문이 없거나 다른 대상이면 심사를 차단한다.
  심사 훅은 중복 실행 잠금·완료 ID·성공 후 갱신 실패 경고·재조회 흐름을 유지한다.
  수락은 숨김 처리, 반려는 노출 상태 유지라는 기존 계약과 body 없는 POST를 유지한다.
- 기능 밖 소비자는 라우터의 페이지 2개와 `adminPendingWorkApi`의 신고 집계 1개다.
  외부 참조 3개를 fixture로 고정하며 API/타입/모델이 UI나 훅을 역참조하지 않게 검사한다.
- 기존 장소 병합/검증 페이지 스타일 재사용은 레거시 연결로 유지한다. 구조 이동을
  공통 스타일 소유권 정리 완료로 간주하지 않는다.
