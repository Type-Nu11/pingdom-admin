# 관리자 네이버 지도 전환 (#223)

## 구현 범위

- 관리자 장소 관리의 지도만 NaverMap으로 교체하고 MapHandle/MapMarker 공통 타입을 사용한다.
- 기존 장소 조회·검색·정렬·필터·페이지네이션 및 장소 수정/삭제 API는 변경하지 않는다.
- 현재 목록에서 유한한 위도(-90~90)·경도(-180~180)를 가진 장소만 마커로 표시하며, 지도 표시 건수도 해당 마커 수로 표시한다. 좌표가 없는 장소도 목록·상세에서는 조회할 수 있다.
- SDK 준비 전 선택한 장소는 준비 완료 후 중심을 보정한다. 선택 중 지도/상세 패널 크기 변경을 관찰하여 보이는 영역으로 중심을 다시 맞추고, 종료·선택 변경 시 관찰자와 예약 프레임을 정리한다.
- 지도 내부 메시지가 상세 패널의 조작을 가리지 않도록 지도에 독립 stacking context를 적용한다.
- 상점주 지도·업체 검색의 KakaoMap 및 kakaoPlaceId 등 서버 데이터 계약은 유지한다. #224~#226에서 별도로 전환한다.

## 검증

- 전체 자동 테스트 376개, lint·TypeScript/build 통과.
- `npm run test:admin-naver-map-browser`: 실제 관리자 페이지 + 모의 API/SDK, Chromium 1280px/390px. 지연 로딩 중 장소 선택, 준비 후 중심 보정, 마커 선택, 줌, 목록 접기/열기, 리사이즈, 검색·페이지별 마커 변경, 범위 밖 좌표 제외, 0건, 인증 실패 중 상세 조회/닫기와 재시도 검증.
- `npm run test:admin-target-browser`: 기존 작업 대상 고정·변경 확인 흐름 회귀 검증.
- `npm run test:place-inspector-browser`: PC/좁은 화면, 상세 패널·이미지·운영 작업 진입 회귀 검증.
- 테스트 API는 GET만 허용하며 운영 데이터 생성·수정·삭제를 수행하지 않는다.
- 위 브라우저 결과는 실제 네이버 인증·지도 타일·실서버 데이터·배포 환경 검증이 아니다. 해당 검증은 #221에서 공개 Client ID와 허용된 도메인/테스트 환경을 확인한 뒤 수행한다.
