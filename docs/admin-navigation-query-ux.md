# 관리자 탐색 및 조회 UX (#242)

## 적용 범위

- 관리자 사이드바: 저장된 설정이 없을 때 현재 경로가 속한 그룹만 펼친다. 대시보드는 모든 그룹을 접는다. 장소 정보 검증은 장소 운영이 아니라 검토함에 속한다.
- 기존 sessionStorage v1 설정은 유지한다. 사용자가 접은 현재 그룹을 강제로 펼치지 않고 활성 색상, 접근성 이름과 툴팁으로 현재 위치를 표시한다.
- 사이드바의 세로/가로 스크롤 저장 수명은 기존과 동일하다. 경로 이동과 재마운트에서 유지하며, 새로고침 시 스크롤 복원은 보장하지 않는다.
- DOM 제거 시 정리 함수에서 스크롤을 다시 읽지 않고, 마지막 스크롤 이벤트에서 관측한 위치를 유지한다. 제거 과정에서 스크롤 값이 0으로 바뀌는 경우를 방지한다.
- 메뉴, 제목, 경로 안내, 대시보드와 대기 업무 링크 명칭을 `중복 후보 검토`, `장소 병합·복구`로 맞췄다. 병합/복구 API나 처리 로직은 변경하지 않았다.
- 예약 심사는 복합 조건을 조회 버튼으로 적용한다. 페이지 이동, 새로고침, 실패 후 재시도는 조회에 사용한 조건을 유지한다. 조회/초기화는 1페이지로 이동하고 초기화는 심사 대기/전체 장소로 돌아간다.
- 기간형 이벤트는 기존 조회 방식과 페이지 이동 동작을 유지한다. 초기화는 전체 조건과 1페이지로 돌아간다.
- 두 복합 조회 화면에 조회 조건 및 미적용 변경 여부를 표시한다. 이 표시는 요청 조건이며 요청 성공을 의미하지 않는다. 오류/이전 결과 표시는 기존 목록 상태 처리를 따른다.
- 커뮤니티 신고와 중복 후보의 단순 상태 필터는 기존 즉시 조회를 유지한다. 다른 화면 전체에 조회 버튼을 강제하지 않는다.

## 재현 검증

```sh
node --test tests/admin-navigation-state.test.mjs
node tests/browser/navigation.mjs
node tests/browser/admin-target.mjs
node tests/browser/place-picker.mjs
npm test
npm run lint
npm run build
```

브라우저 테스트는 실제 컴포넌트와 격리된 합성 응답을 사용한다. 업무 API 외부 요청을 차단하고 GET 외 처리는 금지한다.

- 사이드바: 1920x1080, 1366x768, 390x650. 최초 접기, Enter/Space, 숨긴 항목의 Tab 제외, 현재 위치, 사용자 선택 유지, 경로 이동/재마운트 스크롤, 새로고침 설정 유지.
- 예약 심사: 1920x1080, 1366x768, 390x800. 장소 검색, 미적용 상태/잘못된 ID에서 페이지 이동, 적용 조건 새로고침, 조회 검증, 새 조건의 1페이지 시작, 초기화, 합성 500 응답 후 적용 조건 재시도, 빈 결과의 페이지네이션 숨김.
- 기간형 이벤트: 1920x1080, 1366x768, 390x844. 미적용 검색어 상태에서 페이지 이동/새로고침, 조회/초기화 및 기존 장소 선택 회귀 검증.
- 전체 단위 테스트는 목록의 로딩/빈 결과/오류/권한 처리와 기존 승인 대상 보호 로직을 포함한다.

실서버 계정, 승인/반려, 병합/복구, Safari/Firefox 및 실제 보조공학 기기 검증은 하지 않는다. 통합 QA #220/#221은 이 변경만으로 완료되지 않는다.
