# 관리자 장소 검색 입력 (#240)

- 이벤트 등록과 장소 정보 검증의 증빙·재확인 탭은 `AdminPlacePicker`를 사용한다.
- 검색은 기존 `AdminTargetSearch`와 `GET /admin/places` 계약을 재사용한다.
- 선택한 장소명·주소·ID를 표시하고 변경·해제한다. ID 직접 입력은 접힌 보조 입력으로 유지한다.
- 이벤트 수정은 기존 장소 고정 정책을 유지한다. 등록 요청의 `placeId`는 기존 정수 계약을 변경하지 않는다.
- 증빙·재확인의 대상 입력 변경은 조회된 대상, 결과, 편집 상태, URL의 이전 `placeId`를 비운다. 조회 버튼으로 새 대상을 적용한다.
- 대상 초기화 시 진행 중인 증빙·재확인 응답을 무효화한다. 기존 `?placeId=` 직접 진입은 자동 조회한다.
- 검색 모달의 이벤트가 부모 이벤트 등록창으로 전파되지 않도록 차단한다.

## 검증

- `npm test`: 검색 실패·빈 결과·401 인증 해제, 늦은 검색 응답, 장소 선택·해제, 조회 대상 초기화 후 늦은 응답 무시.
- `node tests/browser/place-picker.mjs`: 합성 Axios 응답으로 Chromium 1920×1080, 1366×768, 390×844에서 검색·선택·Escape 포커스 복귀, 이벤트 수정의 장소 고정, 직접 링크, 증빙·재확인 전환, 직접 ID 조회와 가로 넘침 확인. 스크린샷은 출력된 임시 경로에 저장한다.
- 브라우저 fixture는 GET 이외의 요청과 외부 업무 API 네트워크 요청을 차단한다. 운영 이벤트 등록·공개 및 증빙 변경은 수행하지 않는다.
- 실서버 응답·실제 인증 만료 이동·Safari/Firefox 검증은 수행하지 않았다. 모의 검증을 실서버 검증으로 간주하지 않는다.
