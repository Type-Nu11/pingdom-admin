# 장소 신청 처리 이력 필터 (#165)

## 계약

2026-09-16 공개 Admin OpenAPI의 GET /admin/merchant-place-applications 확인 기준이다. 기존 전체 OpenAPI 스냅샷은 이전 수집 기준이며 이번에는 해당 operation의 매트릭스와 이 문서를 갱신한다.

- keyword: 장소명 또는 신청자 username 부분 일치. 앞뒤 공백을 제거하고 빈 값은 생략한다.
- submittedFrom / submittedTo: 처리일이 아닌 신청 제출 시각. Asia/Seoul LocalDateTime을 UTC 변환 없이 전달한다. 양쪽 경계 포함이며 한쪽만 입력할 수 있다.
- 시작이 종료보다 늦으면 요청하지 않는다. DRAFT는 제출 시각이 없어 서버 기간 필터에서 제외된다.
- 처리 결과 전체는 APPROVED, COMPLETED, REJECTED, CANCELED를 반복 status 파라미터로 전달한다. 승인과 완료는 서버의 별도 상태로 유지한다.

## 화면 정책

- 처리 이력 탭에서 검색·결과·기간을 편집한 뒤 조회 또는 Enter로 적용한다. 신청 유형은 기존처럼 즉시 적용한다.
- 편집 중인 값과 적용된 조건을 분리하고 적용 조건을 화면에 표시한다.
- 조건 적용 시 1페이지로 이동하고 선택된 상세/확인창/증빙 미리보기를 닫는다.
- 초기화는 결과·검색·기간·신청 유형을 기본값으로 되돌린다.
- 심사 대기 탭에서는 이력 검색 조건을 보내지 않으며 이력 탭 복귀 시 적용 조건을 복원한다.
- 건수·페이지 수는 서버 응답을 그대로 사용한다. 현재 페이지의 클라이언트 필터링이나 전체 선조회는 하지 않는다.
- 실패를 빈 검색 결과로 표시하지 않으며 최신 요청만 목록을 갱신한다.
