# 핑덤 AI 웹 연동 (#346)

관리자·상점주 웹의 텍스트 채팅은 앱과 같은 Anthropic Messages 형식으로 `POST /ai/chat`을 호출합니다. 운영 이미지의 기존 동일 출처 API 경로를 사용하면 브라우저에서 보이는 기본 경로는 `/api/ai/chat`입니다. 웹 요청을 앱의 공통 AI 중계로 보내는 실제 라우팅과 웹 권한 검증은 [ReverseProxy #13](https://github.com/Type-Nu11/Pingdom-ReverseProxy/issues/13)에서 확인합니다. 기존 앱 경로나 Spring API를 변경하지 않습니다.

- [앱 요청 코드](https://github.com/Type-Nu11/pingdom-app/blob/1b890f60a369dd69294de5bd8d77c01709b318b6/src/v2/modules/voice-assistant/api/aiChatSessionApi.ts#L193-L234)의 모델과 요청 형식을 사용합니다. 최종 응답은 Anthropic JSON만 처리합니다.
- 도구는 관리자 심사 대기 집계, 선택 매장의 승인 대기 예약 집계, 현재 선택된 신청·예약 상세 요약, 역할별 메뉴 안내로 제한합니다. 모델은 매장 ID·상세 ID·이동 URL을 정하지 않습니다. 화면 이동은 안내 링크를 누를 때만 하고, 업무 데이터 변경은 지원하지 않습니다.
- 질문과 기존 대화 이력 외에는 조회 건수와 제한된 상세 필드만 전송합니다. 예약자 이름·전화번호·요청사항, 신청 연락처·증빙·파일 내용은 보내지 않습니다. 사용자가 입력한 명백한 연락처·이메일·인증 정보는 차단하지만 모든 민감 정보의 탐지를 보장하지 않습니다.
- 대화는 브라우저 메모리에만 유지합니다. 계정·역할·선택 매장 전환 시 기존 요청과 대화를 폐기합니다.

## 활성화

기본값은 비활성입니다. 웹 JWT로 관리자·활성 상점주만 경로를 호출할 수 있는지, 공급자 오류가 사용자 인증 오류와 구분되는지, 양쪽 역할의 도구 호출이 왕복하는지를 스테이징에서 확인한 후 이미지 빌드 변수 `VITE_ENABLE_PINGDOM_AI=true`로 활성화합니다. GitHub 배포에서는 같은 이름의 저장소 변수를 사용합니다. 이 변수는 공개 스위치이며 AI 키가 아닙니다. AI 키는 브라우저나 이미지 빌드에 전달하지 않습니다.

로컬 자동 검증: `npm test`, `npm run test:assistant-browser`, `npm run lint`, `npm run build`. 브라우저 검증은 합성 응답으로 실행하며 실제 운영 연동을 증명하지 않습니다.
