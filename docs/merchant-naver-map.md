# 상점주 신규 장소 등록 네이버 지도 전환 (#224)

- 지도는 공통 NaverMap을 사용한다. 클릭과 수동 좌표 변경은 위치만 수정하며 주소 검색을 자동 호출하지 않는다.
- 주소 검색은 JavaScript SDK Geocoder로 호출한다. 공통 로더가 geocoder를 포함하므로 관리자 지도를 먼저 방문해도 같은 SDK를 재사용한다.
- 검색 결과는 한 건이어도 명시적으로 선택한다. 선택 시 도로명·지번·우편번호·좌표를 함께 적용하고, 장소명과 카테고리는 유지한다.
- 누락된 필드는 빈 값으로 두고 직접 입력한다. 기존 필수 항목 검증과 서버 요청 형식은 변경하지 않는다.
- 주소·좌표 수동 편집, 다른 장소 선택, 입력 모드 변경, 언마운트 시 진행 중인 주소 조회를 무효화한다.
- #225에서 업체명 검색을 서버 네이버 API로 전환했다. 지도·주소 조회 준비와 독립적이며 카카오 SDK를 로드하지 않는다. 상세 계약은 merchant-naver-search.md 참고.

## 검증

`npm test`, `npm run lint`, `npm run build`

`npm run test:merchant-naver-map-browser` — 실제 등록 화면과 합성 API/SDK로 1280px·390px 검증:

- 여러 주소 중 명시적 선택 및 우편번호 누락 처리
- 수동 수정 이후 늦은 검색 결과 무시
- 검색 오류와 재검색, 지도 클릭과 좌표 직접 입력
- 서버 업체명 검색, 새로고침 후 빈 입력 유지, 가로 넘침 여부

`npm run test:admin-naver-map-browser`, `npm run test:naver-map-browser` — 공통 로더 변경 회귀 검증.

실제 네이버 인증·서비스 허용 URL·검색 응답 및 실제 신청 저장/증빙/제출은 이 합성 테스트의 검증 범위가 아니다. 허용된 테스트 데이터로 #220/#221에서 별도 확인한다.
