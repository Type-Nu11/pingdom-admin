# 상점주 영업 상태 표시 (#245)

- 별도 워크트리의 fix/merchant-operating-status 브랜치에서 수정.
- 운영 정보와 운영 공지 모두 서버 true/false만 확정 상태로 표시한다.
- null/undefined는 확인 불가, 조회 중은 확인 중, 실패는 확인 불가와 재시도로 구분한다.
- 재조회 시작 시 이전 영업 판정과 확인 시각을 제거한다. 실패 후 이전 영업 판정을 현재 값처럼 표시하지 않는다.
- 서버 checkedAt만 서버 확인 시각으로 표시하며 운영 상태 변경 시각으로 대체하지 않는다.
- 영업시간 저장 후 운영 정보를 재조회한다. 상태 변경은 기존 서버 응답 적용을 유지한다.
- 브라우저 시각으로 영업 여부를 계산하지 않는다. 서버 시간대 이슈 #1740의 해결 여부는 이 웹 검증과 별개다.

## 검증

- 자동 테스트: true/false/null/undefined, 로딩, 실패, 재시도, 장소 변경 및 이전 응답 역전 방지.
- 실제 두 페이지 + 합성 API: 1920x1080, 1366x768에서 미확인/실패/재시도, Enter 키 조작, 가로 넘침 확인.
- 테스트 브라우저는 GET만 허용. 운영 상태 변경 mutation은 실행하지 않음.
- 전체 테스트 395개, lint, build 통과.
- 실제 계정 인증 만료 및 서버 시간대 판정, 변경 모달의 전체 키보드 흐름은 이번 브라우저 검증 범위에 포함하지 않았다.
- 임시 브라우저와 테스트 서버 종료. 기존 사용자 서버 및 다른 작업 디렉터리 변경 없음.
