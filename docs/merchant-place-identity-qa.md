# 상점주 매장 식별 및 성과 범위 검증 (#244)

## 변경 범위

- `GET /merchant-owner/places/{placeId}`의 `name` 및 주소를 공통 선택기에 표시한다. 같은 이름도 주소와 ID로 구분한다.
- 장소가 하나여도 선택기와 매장 정보를 표시하고, 장소가 없으면 기존 신청 동선을 유지한다.
- 홈의 매장명과 사업자 상호/상점주 표시명을 분리한다.
- 전체 성과에 전체 연결 장소 및 기간 제한 없는 집계임을 명시한다. 선택 매장이나 임의 기간으로 필터링하지 않는다.
- 홈의 이전 매장 조회/저장 응답이 현재 선택된 매장 정보를 덮지 않도록 한다.
- 매장 이름 캐시는 로그인 세션 안에서 공유하며 계정/세션 변경 시 초기화한다. 실패한 정보는 ID와 실패 상태를 유지하고 명시적으로 재조회한다.
- API 상세 데이터는 진행 중인 동일 세션/ID 요청만 합친다. 기존 운영 화면의 상세 새로고침은 여전히 서버에 요청한다. 다른 관리자가 바꾼 이름의 실시간 동기화는 제공하지 않으며 재로그인 시 다시 조회한다.

## 모의 검증 내용

- 연결 장소 0/1/여러 개, 중복 ID, 동일한 매장명과 서로 다른 주소.
- 홈에서 선택한 장소를 메뉴/리뷰/예약 설정으로 이동해도 같은 이름/주소/ID로 유지.
- 일부 상세 조회 실패 후 재시도 및 성공한 다른 장소 유지.
- 401 인증 만료와 403/404/500 조회 실패의 인증 초기화 정책 구분.
- StrictMode 효과 재실행, 계정 세션 변경, 이전 계정의 늦은 응답 무시.
- 동시 상세 요청 중복 제거 및 후속 상세 새로고침의 최신 응답 수신.
- 빠른 홈 선택 전환 중 이전 장소의 늦은 응답 무시. 선택 변경으로 전체 성과를 다시 필터링/조회하지 않음.
- 선택기 키보드 이동, Escape 닫기, 포커스 복귀, 긴 목록 내부 스크롤, 같은 장소 재선택 시 편집 내용 유지.
- 지정된 데스크톱/노트북 크기에서 수평 넘침 없음. 홈 스크린샷에서 매장 정보와 성과 구역 분리 및 글꼴/아이콘 렌더링 확인.

## 검증 한계

브라우저 검증은 실제 페이지 컴포넌트와 합성 API 응답을 사용했다. 실제 로그인, 실서버 매장명/주소, 실제 성과 수치 및 운영 mutation은 수행하지 않았다. 전체 통합 QA는 #220에서 별도로 추적한다. 모든 모달/업무 동선을 새로 전체 검증한 것은 아니다. 임시 검증 서버와 브라우저는 종료했으며 사용자 5173 서버는 변경하지 않았다.
