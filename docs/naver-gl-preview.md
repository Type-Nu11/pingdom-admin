# 네이버 GL 지도 전환 (#237)

## 적용 범위

- 공통 NaverMap을 사용하는 관리자 /places와 상점주 /merchant/place-registration에 GL을 적용한다.
- 로더는 submodules=gl만 요청한다. GL에 필요한 NAVER SDK는 유지하고 기존 raster 확대·축소 컨트롤러 및 SDK Geocoder 구현은 제거했다.
- 합성 데이터 검증 페이지 /dev/naver-gl.html은 기본 Vite build 입력과 앱 라우트에 포함되지 않는다.

## 지도 동작

- gl: true, 초기 줌 15, 범위 6~20. 기존 지도 대비 마커 크기는 줌 +1 보정으로 유지한다.
- 버튼은 0.55단계, 휠은 pixel 환산값 × 0.0055이며 프레임당 최대 0.55단계다. NAVER 공개 서비스 내부 설정을 복제한 수치가 아니라 로컬 QA에서 조정한 값이다.
- 네이티브 휠은 끄고 작은 zoomBy(..., false)를 프레임당 한 번 실행한다. 입력을 멈추면 다음 프레임 이후 남는 장기 애니메이션 큐가 없다. 같은 프레임의 다수 입력은 상한까지 합치며 반대 방향은 이전 의도를 대체한다.
- 휠은 포인터의 지도 좌표, 버튼은 지도 중심을 기준으로 한다. 지도 밖 브라우저 확대 동작은 막지 않는다.
- 하드웨어 가속 미지원 등으로 이미지 지도로 폴백하면 실제 SDK `renderMode`를 확인해 버튼은 정수 1단계로 조작한다. 작은 휠 입력은 0.55단계 분량까지 누적해 정수 1단계로 적용한다(감도와 임계값을 함께 조정해 필요한 실제 휠 입력량은 유지). 방향 반전·버튼 조작·취소 시 이전 의도를 제거하며 프레임당 최대 1단계다.
- 마커 DOM·포커스·선택을 재사용한다. 지도 맞춤에 마커 크기를 고려한 여백을 주고 크기 변경·위치 이동·전체 맞춤·해제 시 대기 중인 줌을 취소한다.

## 주소 검색

- 서버 [PR #1716](https://github.com/Type-Nu11/pingdom-api/pull/1716)의 GET /users/me/merchant-place-applications/naver-address-search 계약에 연결한다. 검색어는 1~100자, 후보는 최대 10개다.
- 응답 items의 도로명·지번·우편번호·WGS84 좌표를 검증하고 우편번호 null은 빈 값으로 처리한다. 결과는 명시적으로 선택하며 직접 입력을 덮어쓰는 늦은 응답은 무시한다.
- 인증/서비스 중단/시간 초과/요청 제한/비정상 응답을 구분한다. 404·405는 배포 확인 안내를 제공하며 주소·좌표 직접 입력을 유지한다. SDK Geocoder로 자동 복귀하지 않는다.
- **2026-09-28 재확인:** 운영 `/v3/api-docs/merchant`가 200을 반환하며 새 경로와 `searchNaverAddress` operation이 등록돼 있다. 이는 문서 등록 확인이며 인증된 실검색 성공을 검증한 것은 아니다. 별도 통합 QA가 필요하다.

## 커밋 전 재검증 (2026-09-28)

- `npm run lint`, `npm run build`, `npm test` 성공 (388개 통과).
- 아래 브라우저 QA는 2026-09-22의 기존 기록이며 이번 커밋 과정에서 다시 실행하지 않았다.
- 로컬에서 예시 Client ID로 인한 NAVER 401을 확인했다. `.env`는 Git 제외 대상이며 실제 Client ID 설정과 개발 서버 재시작 후 실지도 인증을 재확인해야 한다. Client Secret은 웹 환경변수에 넣지 않는다.

## 검증 기록 (2026-09-22)

- npm run lint, npm run build, npm test (388개 통과).
- 공통 지도·관리자 지도·상점주 지도 브라우저 테스트 모두 1280px/390px 통과. SDK/API는 Mock이며 확대·축소, 포인터 기준, 연속 입력 제한, 선택·포커스, 로더 재시도, 크기 변경, 주소 후보·직접 수정 경쟁 상태·오류 등을 검증한다.
- 사전 검증 페이지에서 실제 GL 캔버스·타일·마커 표시, 휠 기준점, 버튼 연타/방향 반전, 30개 마커 맞춤, 새로고침 시 지도 유지, 1280px/390px 표시를 확인했다. 실제 신청 생성·수정·승인은 수행하지 않았다.
- 실제 관리자 /places 새로고침 후 submodules=gl 단독 로딩, mapboxgl-canvas 생성, 실제 장소 마커·지도 표시 및 버튼/휠 확대축소를 확인했다.
- 트랙패드/모바일 터치/하드웨어 가속 비활성 환경, 장시간/느린 네트워크 정량 성능은 미검증이다.
- 운영 Report-Only CSP의 GL 리소스·Worker 출처 감사는 남아 있다. 이번 변경에서 CSP를 완화하지 않았다. 서버 실검색 배포 확인과 통합 QA 전에는 #237 전체 완료로 간주하지 않는다.
