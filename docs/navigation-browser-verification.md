# 관리자 메뉴 브라우저 검증 (#162)

## 실행

```sh
npm ci
npx playwright install chromium
npm run test:navigation-browser
```

실제 `AdminNavigationMenu`와 관리자 장소 화면의 사이드바 스타일을 사용한다.
MemoryRouter의 경로 전환마다 사이드바를 재마운트하여 페이지 왕복을 재현한다.
업무 화면 본문과 서버 호출은 포함하지 않으며 실제 계정·데이터는 사용하지 않는다.
외부 요청은 UI 폰트 CDN만 허용한다.

테스트는 별도 빈 포트와 임시 캐시를 사용하고 종료 시 브라우저·서버를 정리한다.
합성 화면 캡처는 로그에 표시한 임시 디렉터리에 남긴다.

## 검증 및 수정

- 1280×650 및 390×650 Chromium에서 Enter/Space 그룹 접기·펼치기 확인
- Tab/Shift+Tab이 접힌 그룹의 숨겨진 메뉴를 건너뛰는지 확인
- 메뉴 진입 후 경로 및 활성 상태, 접힌 활성 그룹 안내 확인
- 장소 관리 하위 메뉴를 접은 뒤 링크로 이동해도 접기 유지
- 경로 이동·강제 재마운트 후 실제 스크롤 위치 복원 확인
- 새로고침 후 그룹과 하위 메뉴 접기 상태 유지 확인
- 처리되지 않은 브라우저 예외 없음

변경 전 모바일 가로 위치 160px가 재마운트 후 0px로 초기화되는 것을 재현했다.
기존 코드가 `scrollTop`만 저장·복원하므로 `scrollLeft`도 동일한 수명으로 관리하도록
보완했다. 기존 저장 형식·메뉴 분류·라우팅은 변경하지 않았다.

스크롤은 기존과 같이 페이지 왕복·컴포넌트 재마운트 범위에서 보존하며, 브라우저
새로고침까지 보존한다고 약속하지 않는다. 접기 상태는 기존 sessionStorage 정책을 따른다.
화면 크기나 메뉴 내용이 달라져 기존 위치가 범위를 벗어나면 브라우저가 유효 범위로 제한한다.
