# 예약 시각 계약 정리 (#298)

## 확인 기준

- 2026-10-19 KST, 실제 merchant/admin Swagger를 HTTP 200으로 확인했다. date-time 표기만으로 UTC 의미를 추정하지 않았다.
- 서버 커밋 `2b3dbe258d5c80d3f8f753ff28bf281ba89ac43d`의 `ReservationQuoteService`는 슬롯 LocalDateTime을 주입 Clock의 zone으로 해석한다. `OutboxConfig.outboxClock()`의 Bean은 `Clock.systemUTC()`다. 배포 환경의 별도 Clock 교체까지 독립적으로 검사한 것은 아니다.
- `ReservationResponse`, `AdminReservationResponse`의 reservationStartsAt/EndsAt은 예약에 저장된 LocalDateTime이며, 확인서는 오프셋이 있는 OffsetDateTime과 timezone을 사용한다. 실서버 확인서와 슬롯 표시를 대조한 결과도 아래에 구분해 기록한다.

## 변경

- 예약 전용 `reservationTime.ts`: 슬롯/예약 schedule의 오프셋 없는 값만 UTC로 읽는다. 오프셋이 있으면 그대로 순간을 해석해 이중 9시간 보정을 하지 않는다.
- 입력/슬롯 목록/상점주 홈/예약 snapshot 대체 표시/관리자 schedule/조건 모달 설명은 한국 시각으로 표시한다. 확인서와 취소 기한은 기존의 명시된 offset·timezone을 존중한다.
- 한국 `2026-10-24T14:00` 입력은 UTC `2026-10-24T05:00:00`으로 전송한다. Z나 +09:00를 붙여 LocalDateTime 요청 계약을 바꾸지 않는다.
- 수용 인원만 바꾸는 등 분 단위 입력값이 그대로라면 기존 초·최대 9자리 소수점을 보존한다. 의도적으로 시간을 바꾸면 분 단위, 초 00으로 저장한다.
- 공용 달력은 기본 로컬 모드를 유지한다. 예약 화면만 UTC-shaped Date로 civil fields를 조작하는 wallClock 모드와 한국 기준 today를 전달한다. 뉴욕 DST의 존재하지 않는 02:30이나 반복되는 01:30을 브라우저 로컬 시간으로 정규화하지 않는다.
- 잘못된 날짜/시각을 JavaScript 날짜 rollover로 정상화하지 않는다. 날짜 경계·현재 시각 비교도 UTC 순간 기준이다. 잘못된 응답은 시각 정보 없음/빈 입력으로 표시하고 저장을 차단한다.
- 예약 일정 snapshot이 있으면 현재 수정된 availability보다 우선한다. 기존 예약에서 필드가 없을 때만 availability로 대체한다.
- 예약 생성/검토 같은 감사 이벤트의 오프셋 없는 값은 UTC로 추정하지 않고 원래 civil fields를 유지한다. 명시적 offset이 있을 때만 한국 시각으로 변환한다. 다른 도메인 날짜 함수는 변경하지 않는다.

## 실제 조회와 기존 데이터 주의

- 로컬에 사용자가 로그인한 상점주 계정으로 읽기만 수행했다. 기존 용짬뽕 일정 #6의 서버 값은 10월 24일 14:00~15:00 UTC에 해당하며 새 화면은 10월 24일 23:00~25일 00:00 KST를 표시한다. 기존 예약 확인서도 23:00~00:00 Asia/Seoul로 표시되어 종전 웹의 9시간 차이가 사라졌다.
- 운영 DB를 직접 조회하거나 이 검증에서 예약별 availabilityId 응답을 별도로 추출한 것은 아니다. 위 기록은 실제 화면 조회 대조다.
- 기존 점주가 의도했던 14:00 KST 일정으로 데이터를 자동 이동하지 않았다. 이미 예약된 일정·수용 인원·조건·승인·취소·환불은 일절 변경하지 않았다. 기존 잘못 입력된 일정의 정정은 영향 확인과 별도 승인 대상이다.

- `node --test tests/reservation-time.test.mjs`: UTC/KST 왕복, 자정/월/연도/윤일, 오프셋 응답, 나노초 보존, 잘못된 날짜, 현재 시각, 확인서 표시/취소 기한 경계.
- `npm run test:reservation-timezone-browser`: 실제 Router·예약 설정·API 함수와 엄격한 메모리 adapter, 서울/UTC/뉴욕 × 1920×1080/1366×768/390×844. 수용 인원 수정 시 precision 보존, 달력 날짜/시간 조작, DST gap 02:30, UTC 본문, 한국 시각 재조회, 관리자 상세 읽기 대조. 실제 API 네트워크는 차단한다.
- 기존 setup/terms/conditions/context 브라우저 회귀를 별도로 실행한다. 공용 달력 기본 모드의 기존 사용 흐름도 이 회귀 범위에 포함된다.
- 스크린샷의 외부 폰트/아이콘 픽셀은 검증하지 않는다. 합성 저장 성공은 운영 PUT 성공이 아니다. 전체 실서버 DB/운영 시계 설정, Safari/Firefox, 실기기 터치, Docker 검증은 별도다.
- 예약 상품·가격·결제 표시 정리는 #297, 원본 OpenAPI 전체 갱신은 #302에 남는다. 계약표 6개 관련 행에 이번 의미 대조 기록만 추가했다.
