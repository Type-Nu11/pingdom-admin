# 신청 심사 작업 영역 검증

실행: `npm ci`, `npx playwright install chromium`, `npm run test:review-actions-browser`.

기존 증빙 검증 화면에 `review` 옵션으로 긴 합성 장소명을 공급한다. 운영 데이터나 인증 정보는 사용하지 않으며 실제 API 통신은 차단한다. 테스트 서버와 Chromium은 종료 시 정리한다. 캡처 위치는 실행 로그에 출력된다.

## 비교

같은 신청과 화면 크기에서 작업 영역 직전 본문 높이를 측정했다. 하단 대상명은 두 줄로 제한하고 전체 텍스트는 DOM, title, 상세 및 확인창에 유지한다.

| 화면 | 수정 전 본문 높이 | 수정 후 본문 높이 |
| --- | ---: | ---: |
| 1280 × 800 | 311px | 370px |
| 1280 × 600 | 128px | 187px |
| 390 × 800 | 199px | 317px |
| 390 × 600 | 69px | 187px |

## 자동 검증 범위

- 본문 읽기 영역 120px 이상, 작업 영역과 본문 비중첩
- 작업 영역으로 이동한 뒤 버튼이 화면 안에 있고 본문 스크롤로 움직이지 않음
- 본문 끝에서 마지막 증빙 버튼에 접근 가능
- 승인 버튼이 기존 확인창으로 연결되고 Escape로 닫힘
- 승인 완료된 다른 신청 선택 시 읽기 전용 상태로 전환
- 가로 넘침 없음

기존 `application-review-actions.test.mjs`는 상세 로딩 중 이전 작업 숨김, 여러 읽기 전용 상태, 승인 차단 사유 및 확인창 진입 전 변경 요청 미실행을 검증한다. `test:attachment-browser`는 증빙 도구의 키보드·다운로드·오류 처리를 별도로 검증한다.

모바일은 목록과 상세가 세로 배치되므로 페이지 스크롤로 상세에 진입한다. 페이지 전체에서 작업 버튼이 항상 고정된다는 의미는 아니다. 실서버 승인·반려, 운영 배포, Safari/Firefox 및 실제 보조공학 기기 검증은 포함하지 않는다.
