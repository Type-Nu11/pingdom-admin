## 적용

관리자·상점주 모두 Pretendard를 사용하며 Title1 28, Title2 24, Headline1 20, Headline2 18, Body 16, Label 14, Caption 12px입니다. 굵기는 Bold 700, Medium 500, Regular 400이며 공통 제목·버튼·폼·배지는 `typo` 명명 스타일을 참조합니다. 11/13/15/30px과 600/800 굵기를 제거했습니다. 페이지 제목은 Title1로 통일했습니다.

기본 글자색·배경·구분선은 기존 토큰이 원본과 일치합니다. 불일치한 성공 강조색은 `#20C831`로 수정했습니다. 임의의 초안·상태 문구 색상은 Foundation 팔레트로 교체했습니다. 아이콘의 19/21/22px 같은 크기는 글자 단계가 아닌 아이콘 크기이므로 유지합니다. 긴 리뷰·안내 본문의 넓은 행간도 가독성을 위해 유지합니다.

## 대비와 원본의 확인 사항

- Primary/Normal `#FF1956`으로 버튼·선택 메뉴·강조 문구를 통일합니다. 사용자 요청에 따라 진한 핑크 확장을 제거했고 `primaryAction`/`primaryForeground`는 메인 컬러의 호환 별칭입니다. 흰색과의 대비는 약 3.8:1로 작은 글자 AA 기준(4.5:1)을 충족하지 않습니다. 오류 메시지의 빨간색과 의미가 있는 성공·경고 상태색은 유지합니다.
- 상태 전경은 Red40, Blue40, Green20, Yellow20을 사용해 밝은 상태 배경에서도 읽을 수 있게 합니다.
- Figma의 Caption Regular 행은 이름·표에는 Regular로 표기되어 있으나 연결된 샘플 폰트는 Medium입니다. 이름에 맞게 Regular 400을 적용했습니다. 디자인 원본은 수정하지 않았습니다.
- Figma get_variable_defs 응답에서 Line/Neutral은 누락되어, 보드의 실제 스와치 `#F2F2F3`을 확인했습니다.

## 회귀 기준

공통 상점주 스타일의 해시 기준은 이 의도적인 디자인 변경에 맞춰 갱신했습니다. 선택 상태·API 및 제재 처리 핸들러는 변경하지 않습니다. 기존 구조 테스트와 별도로 Figma 수치 비교·브라우저 실제 스타일 검사를 유지합니다.

검증은 실제 컴포넌트를 합성 데이터로 렌더링하는 Chromium 회귀 검사입니다. 1920×1080, 1366×768, 390×844에서 스타일 계산값, 줄바꿈·가로 넘침, 입력 유지, 모달·키보드 동작을 확인합니다. 외부 폰트 CSS는 테스트에서 차단하므로 Figma와 Pretendard 글리프의 픽셀 단위 비교나 실제 배포 서버의 전체 업무 검증을 의미하지 않습니다. 실제 운영 요청은 차단합니다.

브랜드 색상 통일 전에는 144개 대비 검사가 모두 4.5:1 이상이었습니다. 통일 후에는 브랜드색 사용과 대비 미달을 구분해 기록하며, 오류·중립·상태 문구는 기존 AA 검사를 유지합니다. 확인한 디자인 원본 값은 색상 변수 110개와 타이포그래피 21개 스타일입니다.

## 긴 텍스트와 안내문

- 한국어는 어절 단위 줄바꿈을 우선하고 긴 이메일·주소 등은 화면 너비 안에서 줄바꿈합니다. 글자 크기를 줄이거나 내용을 숨겨 해결하지 않습니다.
- 신규 장소 등록·운영 권한 신청의 전화번호 예시는 한 덩어리로 표시합니다. 안내문은 부모 라벨의 Bold를 상속하지 않고 Caption Regular를 사용합니다. 전화번호 입력·검증·전송 규칙은 변경하지 않습니다.
- 첨부파일명·업로드 안내, 관리자 상세 제목·주소·영업시간, 장소 병합 비교·확인 정보, 상점주 홈의 업무 정보는 전체 내용을 표시합니다. 필터·날짜·첨부 종류의 선택값은 필요하면 여러 줄로 확장됩니다.
- 좁은 화면의 신규 장소 신청 폼은 한 열로 배치하고 영업시간 컨트롤은 가로 넘침 없이 재배치합니다. 상세에서 전체 내용을 확인할 수 있는 목록 미리보기와 보조기술 전용 숨김 텍스트는 유지합니다.
- `text-readability` 브라우저 회귀 검사는 1920×1080, 1449×772, 1366×768, 620×844, 390×844, 320×768에서 실제 스타일과 합성 API를 연결한 신청 폼을 점검합니다. 예시 줄 수, 잘림·가로 넘침, 안내 굵기, 키보드 선택·포커스, 화면 크기 변경 시 입력 유지가 검증 대상입니다.
